One word for the whole internet: **Cookies** — the snack you can't eat, on every site you visit.

## Entry

`main.ts` writes the single word `Cookies` to `/output/entry.txt` (or
`$MAKEFUN_OUTPUT_DIR/entry.txt`), with a gate that rejects anything that is
not one word of 1–30 characters.

## Run

```sh
node main.ts
cat /output/entry.txt
```
